# EMSI REST Parity Example

These files document the expected inputs and output for future REST-to-GraphQL
parity checks.

- `rest-response.example.json`: captured REST response.
- `graphql-response.example.json`: captured GraphQL response.
- `field-mapping.example.json`: explicit JSON-path equivalence mapping.
- `diff-report.example.json`: example diff report shape.
